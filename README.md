# EMORA V4 · Light Atelier — Public Showcase

This deployment is a public design showcase for the seven V4 editions: two Love, two Wedding, Birthday, Apology, and Proposal. It contains no private photos, music, payment gateways, customer accounts, editor API, or RSVP database. The complete editable V4 source is a separate ZIP package; deploy that source after persistence, operator authentication, and production smoke tests are configured. All preview pages are self-contained HTML. Start: `npm start`.
