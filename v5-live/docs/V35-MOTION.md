# V35: authored motion

The four personal gifts retain their scenarios, languages, user uploads and bot notification boundary.

Proposal: an actual Three r160 mesh scene builds a velvet case with a hinged lid, gold band, faceted gemstone and prongs. Opening lifts the ring while the camera approaches. The early tease only lifts the lid slightly; it never reveals the ring. Physical materials, studio environment and one shadow light create depth.

Birthday: a separate mesh scene builds the cake, porcelain plate, icing and five individual candles. Existing native buttons are projected onto their 3D positions so keyboard and touch still invoke the original candle state. Smoke is short-lived after each click.

Apology and confession: a bounded wax-seal / flap / envelope / ink sequence opens the original authored letter. Rapid repeated clicks cannot create another sequence. Next stays disabled only during the release. Reduce-motion shows the letter immediately. Personal photos lead the opening and galleries use native horizontal scroll-snap on narrow screens.

Final name glyphs remain the existing rectangle → heart → rectangular portrait algorithm. No raster photograph is added to its visible canvas.

The 3D library is local and lazy-loaded only when an actor is visible. One renderer is reused across proposal stages, resolution is capped at 1.4x and drawing is bounded to active scenes. Unsupported or lost WebGL retains the original interactive CSS scene. Static scripts/styles use cached gzip.

Verification: real mesh geometry finite-values, hidden teaser ring, opened ring and hinge, independent five-candle state; DOM letter repeat-click and completion; personal-photo selection; reduced-motion behavior; unavailable-GPU fallback. Syntax and CSS structure checked. These checks are not a rendered WebGL or phone visual review; supported browser control is unavailable.
