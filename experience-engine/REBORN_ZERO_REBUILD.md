# EMORA Reborn V1 — Zero Rebuild Charter

This branch intentionally keeps only proven product plumbing: creator/editor state, content model, publishing contracts, Railway/GitHub deployment, and automated QA.

The experience layer is rebuilt from zero.

## Reference quality
- No generic card layouts.
- No repeated envelope/open/scroll pattern across templates.
- Every experience behaves like a short film with one continuous visual world.
- Gestures manipulate objects or environments, never arbitrary UI.
- Every gesture causes a physical consequence.
- Camera movement, lighting, material and typography are choreographed together.
- 3D/WebGL is used as narrative space, not decoration.
- Every template gets a false ending or emotional breath before the final payoff.
- Mobile 390x844 is the primary stage, not a reduced desktop view.
- Recipient flow has zero document scroll.

## First flagship
Pearl Linen — The Private Archive

Narrative:
1. A pearl wakes over living linen.
2. Dragging the pearl pulls a gold thread and stitches the recipient's name.
3. The same thread reveals a linen archive folio.
4. Holding the seal fractures it and opens the physical folio.
5. One sheet rises toward camera; the letter appears in ink over time.
6. A single horizontal gesture scrubs three memories as one continuous archive.
7. The archive collapses and the screen goes almost completely dark.
8. The pearl returns and thousands of luminous points assemble a personal signature mark.
9. Final copy arrives only after the particle mark settles.

Old Pearl visual/runtime code is not used by the recipient or editor preview in this branch.
